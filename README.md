# ms-app

A companion app for people with multiple sclerosis. One input line: voice, text, a food photo. Coincidences, not causes. A summary for the doctor.

Open: https://julie566.github.io/ms-app/

- `v5.html?v=5b&lang=en` minimum: no context line, one or two chips
- `v5.html?v=5&lang=en` with the context line and the hint
- `&lang=ru` for Russian

Inside the app: say “english” / “по-русски”, or settings → language. Moderator screen: say “all states” / «все состояния».

Not a medical app. Entries are stored only in the browser.
