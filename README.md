# ms-app

Прототип приложения-помощника для людей с рассеянным склерозом. Одна строка ввода: голос, текст, фото еды. Совпадения, не причины. Сводка к врачу.

Открыть: https://julie566.github.io/ms-app/

- `v5.html?v=5b` минимум: без контекстной строки, один-два чипа
- `v5.html?v=5` с контекстной строкой и подсказкой

Переключение прямо в приложении: написать в строке «v5» или «v5b». Не медицинское приложение. Записи хранятся только в браузере.
