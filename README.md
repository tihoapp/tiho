# ms-app

Прототипы приложения-помощника для людей с рассеянным склерозом. Одна строка ввода: голос, текст, фото еды. Совпадения, не причины. Сводка к врачу.

Открыть: https://julie566.github.io/ms-app/

- `v5.html` текущая версия, один экран
- `v4.html` версия с вкладками и историей
- `p1.html` первый прототип

Не медицинское приложение. Данные прототипа хранятся только в браузере.
